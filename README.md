# VETA Retro 1.0.0 · candidata 3

Código de la edición pública para iPhone, compilación 202. [Notas y guía de esta entrega](RELEASE-1.0.0-rc.3.md).

## Fuentes completas

Descarga [el paquete completo de fuentes](https://github.com/wmarquezz/veta-retro-public/releases/download/v1.0.0-rc.3/VETA-Retro-1.0.0-rc.3-sources.tar.gz). Incluye código de la app, motores, dependencias, parches, avisos y receta. **No requiere archivos de entregas anteriores.** El repositorio visible es un subconjunto de revisión; el archivo de la versión es la entrega completa.

Comprueba su SHA-256 con SOURCE-RELEASE.json y, tras extraerlo, ejecuta `python3 apple/native/BuildSupport/source_release/verify.py .` desde veta-public-source. Sigue después README.md del archivo para reconstruir con tu propia firma.

La versión visible usa 1.0.0; las correcciones seguirán 1.0.1 y las nuevas funciones 1.1.0. El número interno de compilación aumenta siempre. La etiqueta rc indica una candidata, no una app aprobada por Apple.
