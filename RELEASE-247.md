# VETA Retro 1.0.0 — build247, source candidate45

Complete corresponding-source package for public build247 uploaded to Apple. It includes native application sources, pinned engine sources and dependencies, build recipes, third-party notices, and the two MIT samples. It does not contain the personal game library, commercial ROMs/BIOS, signing keys or pairing credentials. Original VETA contributions use GPL-3.0-or-later; third-party components retain their licenses.

Build247 adds a visible Included games flow with an explicit Close action and eight translations. It retains the iPad library safe-area correction and19 engine framework code sections from246.

Evidence:12 final UI test executions passed on physical iPhone11 and iPhone/iPad simulators. Eighteen physical engine test cases in246 cover20 public consoles; unchanged engine code carries this representative regression forward. This is not certification of all games, sustained full-speed performance, every lifecycle combination, TV or multiplayer.

This source release is not an App Store approval. Engine/channel licensing assessment DIST-01 remains open. ART-01 was closed on the owner’s explicit confirmation of VETA-authored designs created with references and adapted to their needs; the designs are unchanged. Publishing sources fulfils the source-availability step; it does not manufacture third-party permissions.

The prepared package includes a complete per-file manifest. Verify every file with apple/native/BuildSupport/source_release/verify.py and follow README.md for preparation/build requirements. The release attachment and its SHA256 checksum identify the exact247 source snapshot; historical files in the repository's main branch may describe older builds.
